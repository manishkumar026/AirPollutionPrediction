# 🌍 Air Pollution Prediction System

A complete AI-powered Air Quality prediction dashboard with 3D animations.

## 🚀 Quick Start

### Step 1: Get API Keys (FREE)
1. **OpenWeatherMap**: https://openweathermap.org/api → Sign up → Copy API key
2. **WAQI**: https://aqicn.org/data-platform/token/ → Get token

### Step 2: Configure API Keys

**Backend** → Open `backend/api/config.py`:
```python
OPENWEATHER_API_KEY = "paste_your_key_here"
WAQI_API_TOKEN      = "paste_your_token_here"
